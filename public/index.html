Base URL: http://localhost:3000

GET /api/attendance
Fetch paginated attendance logs. Filter by date, user, device, io_mode.
?page=1&limit=20
?date=2025-01-15
?user_id=123
?io_mode=0  (check-in)
?io_mode=1  (check-out)
?from=2025-01-01T00:00:00
?to=2025-01-31T23:59:59
POST /api/attendance
Manually log an attendance record.
{
  "user_id": "42",
  "dev_id": "GATE_01",
  "io_mode": 0,
  "verify_mode": 1,
  "io_time": "2025-01-15T09:00:00"
}
GET /api/attendance/export/csv
Download all attendance logs as a CSV file.
Returns: text/csv download
DEL /api/attendance/:id
Delete a single attendance record by ID.
DELETE /api/attendance/15
GET /api/enrollments
List all enrolled users.
?page=1&limit=20
POST /api/enrollments
Manually enroll a new user.
{
  "user_id": "42",
  "user_name": "Alice",
  "user_privilege": "0",
  "dev_id": "GATE_01"
}
GET /api/devices
List all registered biometric devices.
Returns dev_id, firmware, last_seen,
ping_count per device
POST / (Device Push)
Biometric device endpoint. Device sets request_code header.
Headers:
  request_code: realtime_glog
  dev_id: GATE_01

Body (binary+JSON):
  { "user_id":"42",
    "io_mode":0,
    "io_time":"2025-01-15T09:00" }

🔧 Biometric Device Configuration

Configure your biometric reader to push attendance data to this server.

Server URL (set in device admin panel)
Supported Request Codes
receive_cmd Device heartbeat / firmware info
realtime_glog Attendance punch (check-in/out)
realtime_enroll_data New user enrollment event

🐧 Linux Server Setup

1. Install Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
2. Clone & Install
git clone https://github.com/you/attendance-system
cd attendance-system
npm install
3. Run with PM2 (auto-restart)
npm install -g pm2
pm2 start src/server.js --name biotrack
pm2 startup   # auto-start on reboot
pm2 save
4. Open firewall port
sudo ufw allow 3000/tcp
sudo ufw reload
5. Test device endpoint
curl -X POST http://localhost:3000/ \
  -H "request_code: realtime_glog" \
  -H "dev_id: TEST_GATE" \
  -H "Content-Type: application/json" \
  -d '{"user_id":"1","io_mode":0,"io_time":"2025-01-15T09:00:00","verify_mode":1}'
